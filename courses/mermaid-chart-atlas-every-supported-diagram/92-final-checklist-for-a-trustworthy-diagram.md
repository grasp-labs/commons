---
title: Final checklist for a trustworthy diagram
---
## Syntax

- [ ] The code fence is named `mermaid`.
- [ ] The first line selects the intended diagram family.
- [ ] Identifiers are stable and labels are readable.
- [ ] Quotes, indentation, brackets, and closing blocks are balanced.
- [ ] The diagram renders instead of falling back to source.

## Communication

- [ ] The chart answers one explicit question.
- [ ] Direction, order, units, and scales are explained.
- [ ] Every relationship or branch that needs meaning has a label.
- [ ] The visual contains only information needed for the decision.
- [ ] A table or sentence would not explain the idea more clearly.

## Presentation

- [ ] Labels remain readable at the normal course width.
- [ ] Fit shows the whole model; zoom reveals detail.
- [ ] Light and dark mode both preserve contrast.
- [ ] The chart is split when it becomes a poster.
- [ ] The surrounding Markdown explains what the learner should notice.

> The best Mermaid diagram is not the most advanced one. It is the smallest diagram that makes the right relationship obvious.
