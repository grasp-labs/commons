## Runtime information: verify Mermaid availability

**Atlas example 27 of 44**

Use the info diagram as a lightweight runtime check when diagnosing which Mermaid version is active.

### Core Mermaid elements
- The complete source is simply info.
- No nodes, edges, or title are required.
- Mermaid returns its runtime information.
- AI Commons adapts the result into the standard visualization container.

### Build it well
1. Use it for diagnostics, not teaching a business concept.
2. Confirm it renders before debugging complex syntax.
3. Record the observed version when reporting compatibility issues.
4. Return to a real diagram after the environment is verified.

> A successful info chart proves the renderer loaded; it does not prove every diagram is valid.
