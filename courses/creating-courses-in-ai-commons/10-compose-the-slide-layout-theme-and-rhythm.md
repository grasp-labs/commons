## One column

Best for:

- a focused introduction;
- one large diagram;
- a procedure or checklist;
- content that needs the full width.

Use the single-column layout when there is no meaningful comparison.

> Empty space is part of the design. Do not add another column merely because it is available.

<!-- ds-course-column:2 type=markdown -->

## Two columns

Best for:

- concept + example;
- Mermaid source + rendered result;
- explanation + image;
- before + after.

Drag the resize handle when one side deserves more attention. The narrower column should contain the simpler content.

Keep both columns connected by one shared idea.

<!-- ds-course-column:3 type=markdown -->

## Three columns

Best for:

- three comparable choices;
- compact reference groups;
- a short framework with three parts.

Three columns leave less room for prose. Use short headings and lists.

### Theme and rhythm

Choose one course theme and keep it consistent. Alternate dense reference slides with simpler visual slides so the course can breathe.
