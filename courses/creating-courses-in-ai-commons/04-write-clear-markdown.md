## Core syntax

```text
## Section heading

A short paragraph with **bold emphasis**
and a [useful link](https://example.com).

- one idea
- a second idea
- a final action

1. first action
2. next action

> A callout for an important note.

---

Inline code: `bun run check`
```

Use `#`, `##`, and `###` to create hierarchy — not merely to make text larger.

<!-- ds-course-column:2 type=markdown -->

## Write for scanning

| Prefer | Avoid |
|---|---|
| Short paragraphs | Walls of text |
| Descriptive headings | “More information” |
| One idea per bullet | Paragraphs disguised as bullets |
| Concrete verbs | Vague introductions |
| Examples near the rule | Examples several steps later |

### A useful rhythm

1. **Explain** the idea.
2. **Show** a realistic example.
3. **Ask** the learner to apply it.

> If a slide needs five headings, it probably wants to become two slides.
