## Markdown media syntax

```text
[Open the reference guide](https://example.com/guide)

![A descriptive explanation of the image](https://example.com/image.png)
```

### Accessibility first

- Write alt text that explains the **meaning**, not just the appearance.
- Keep linked text descriptive; avoid “click here”.
- Use stable HTTPS URLs.
- Compress images before uploading: covers, backgrounds, and Image columns must be 2 MB or smaller.
- Never put essential instructions only inside an image.

Raw HTML is disabled. For video, add a clear link to the recording instead of an HTML `<video>` or `<iframe>` embed.

## Choose the right image method

### Use a Markdown image when

- the image belongs inside an explanation;
- text should flow directly before and after it;
- the source is already available through a stable URL.

### Use an Image column when

- the visual is a main part of the slide;
- it should sit beside Markdown;
- you need explicit **top, center, or bottom** alignment.

### Use the course cover for

- recognition on the course gallery;
- a consistent first impression;
- a visual identity that works in a wide card crop.

> Preview the real course — not only the editor — before publishing.
