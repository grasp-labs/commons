## Steps sidebar

- Select a step to edit it.
- **Add step** appends the next lesson.
- Drag a step to reorder it.
- The status under each title shows **Content added** or **Needs content**.
- **Remove step** (trash icon beside the step title) deletes the selected lesson when you save.

Write the step title as the learner’s next idea or action, not “Step 3”.

<!-- ds-course-column:2 type=markdown -->

## Build the slide

- Choose **1, 2, or 3 columns**.
- Drag the dotted handle to resize neighbouring columns.
- Use the move action only when a column can actually move left or right.
- Choose **Markdown** or **Image** for each column.
- Click a preview to edit it; leaving the editor returns to preview mode.

One column uses the full available width.

<!-- ds-course-column:3 type=markdown -->

## Image controls

For an Image column:

1. upload the visual;
2. add useful alternative text;
3. choose top, center, or bottom alignment;
4. preview the complete slide.

### Header actions

- Preview — open the course player
- Public — new courses, platform tenant only
- Share — manage access
- Delete — remove the course
- Cancel — leave edit mode
- Save draft — keep work unpublished
- Publish course — save and make the course active; every column needs content and every image a description
