title: Know which Mermaid diagrams AIC supports
---
## Flows and structures

AIC has enhanced rendering for:

- Flowchart
- Class diagram
- Entity relationship
- State diagram
- Requirement diagram
- Mind map
- Architecture
- Block diagram
- C4
- Tree view

Use these to explain **what exists**, **how parts connect**, and **how state changes**.

<!-- ds-course-column:2 type=markdown -->

## Sequence and planning

AIC has enhanced rendering for:

- Sequence diagram
- Gantt
- Timeline
- User journey
- Git graph
- Kanban / board
- Swimlane
- Event modeling

Use these to explain **who acts**, **in what order**, and **how work moves over time**.

<!-- ds-course-column:3 type=markdown -->

## Data and decisions

AIC has enhanced rendering for:

- Pie and XY chart
- Radar and Sankey
- Treemap and quadrant
- Venn and Cynefin
- Wardley map
- Ishikawa
- Packet
- Railroad
- Info

Other valid Mermaid types can use Mermaid's native SVG fallback. Always preview the result because syntax and layout differ by diagram family.
