## Share from view or edit mode

Select **Share** in the top action bar.

1. Enter an email address, or select **Share with everyone**.
2. The new entry starts with **View**; switch it to **Edit** if needed.
3. Remove it when access is no longer needed.

In view mode the change is saved immediately; in edit mode it is saved with the course. The same access list is written to every file in the course, so the course behaves as one resource.

## View and Edit are different

| Permission | Stored as | Allows |
|---|---|---|
| View | viewer | Open and complete the course |
| Edit | owner | Edit, share, and delete the course |

The creator remains an owner.

**Public visibility is not Edit access.** A public course is available in every tenant, but only the platform tenant can change, share, or delete it — even Edit access does not let another tenant manage it.

> Use **Share with everyone** deliberately. Prefer named users for collaboration.
