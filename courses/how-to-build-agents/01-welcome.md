# How to build Agents

An *agent* is software that can understand a request, decide what to do, and then *do it* — by calling tools, looking things up, or taking actions on your behalf. This course is a practical, hands-on guide to building one.

We start simple — with **Microsoft Copilot Studio**, where you can stand up a working agent without writing code — and then grow into other kinds of systems on later pages.

## What you will learn

- What an agent actually is, and the parts it is made of
- How to choose a platform — and why we start with Copilot Studio
- How to build a basic agent in Copilot Studio
- How to extend an agent with **actions** and the **Model Context Protocol (MCP)**
- How to connect an MCP server as a tool source for your agent *(page coming)*
- How to test, publish, and then grow beyond Copilot *(page coming)*

> **How this course is organised:** it is built to grow. Each kind of system you can build agents from gets its own page. We begin with Copilot Studio; add more pages as you adopt new platforms.

> **What about agents inside AI Commons?** A native Commons *agent block* (a versioned agent definition run as a job, like a workflow) is designed but **not available yet**. Today you build agents on an external platform and give them Commons tools through the AI Gateway's MCP server.

> **Who this is for:** builders, analysts, and team leads who want a working agent — no deep engineering background required.
