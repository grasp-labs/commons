## Choosing a platform — and why we start with Copilot Studio

You can build agents from many kinds of systems. Each trades off *ease* against *control*.

| Platform | Best for | Effort |
| --- | --- | --- |
| **Copilot Studio** | Team agents inside Microsoft 365, no code | Low |
| Azure AI / OpenAI Assistants | Custom apps, full control | Medium |
| LangChain / LlamaIndex (code) | Bespoke pipelines, developers | High |
| Self-hosted MCP servers | Sharing tools across many agents | Medium |

### Why start with Copilot Studio?

- **No code to begin.** You describe the agent in plain language.
- **Lives where your team already works** — Teams, M365, the web.
- **It still scales.** You can add *actions* and *MCP servers* when you need real tools — which is exactly what we do later in this course.

> **The plan:** build a working Copilot Studio agent first, then give it real capabilities by connecting an MCP server. Later, add a new page per platform as you adopt it.
