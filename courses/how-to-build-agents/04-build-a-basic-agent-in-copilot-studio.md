## Build a basic agent in Copilot Studio

Let's stand up a working agent before we add any tools.

### Steps

1. Go to **copilotstudio.microsoft.com** and sign in with your work account.
2. Select **Create → New agent**.
3. Describe the agent in plain language (Copilot Studio drafts it for you), or choose **Skip to configure** to set it up manually.
4. Give it a **name**, a short **description**, and clear **instructions** (the system prompt).
5. Add **Knowledge** if you want it to answer from your docs or websites.
6. Use the **Test** pane on the right to chat with it as you build.

### Writing good instructions

Good instructions are specific. State the agent's role, what it should and should not do, the tone, and what to do when it is unsure.

> **Tip:** keep the first version small. Get a plain Q&A agent working and tested first — then add tools on the next page.
